# 整合式影像處理軟體驗收與已知限制

文件版本 1.0　核對日期 2026-10-30　程式基準 b512791

本文件把已知程式風險與設備驗收案例列在一起。以下案例是待執行的驗收規格，並非通過紀錄。本次完成文件與靜態核對，未接相機、米輪、公司影像或跨站網路。

## 1 已知限制

| 編號 | 狀態與影響 | 處理建議 |
|---|---|---|
| L01 | 高優先；離開總覽時本機連續檢測轉送可能中斷，旗標仍顯示活動 | 先修轉送規則，再獨立 runtime；以影格序號實測 |
| L02 | 高優先；TCP 舊 peer 清理可能移除同站新 peer | 清理比對實例／ConnectionId，避免同站重疊重連 |
| L03 | 歷史無當時全域精度，重跑 mm 值與尺寸篩選可能改變 | 保存並於重跑使用標定快照 |
| L04 | 檢測借用結果確認 UI，歷史尺寸明細讀 Grid | 建立共同 Request／Result 與記錄 mapper |
| L05 | 巢狀平行及背景保存無一致 CPU／RAM 預算 | 設全局排程與有容量上限的保存 worker |
| L06 | 設定驗證和運算式 parser 分開，錯誤式可能保存後才失敗 | 共用 TryParse 和 evaluator |
| L07 | 各頁固定尺寸 GroupBox 及主欄寬還原邏輯複雜 | 用實際 DPI 檢查，逐頁 UserControl 化 |
| L08 | 角色無登入／授權，Operator 與 Engineer 尚無編輯差異 | 正式權限另立需求與稽核規格 |
| L09 | TCP 最新狀態不保證每筆結果送達，無可靠結果佇列 | 定義 RunId、ACK、重送、去重與持久化 |
| L10 | 存圖和 DB 非同一交易，關閉時無完整保存工作排空管理 | 加每筆保存狀態、錯誤與關閉策略 |
| L11 | 全域 Y 高度限制目前僅在相機入口；手動拒收不一定記錄 | 共用輸入驗證與拒收結果模型 |
| L12 | 尺寸 mm 開關不控制缺陷 X/Y mm 篩選 | 明確記錄現況，若要統一須另做相容性評估 |

L01、L02 是依程式路徑推導出的具體競態／流程問題，仍需重現。L03、L04、L08、L09、L11、L12 可由資料模型或呼叫位置確認。其他負載與 UI 問題的程度需量測。

## 2 驗收資料集

建立一份固定測例清單，包含原圖 hash、Recipe hash、ParameterId、設備精度、預期物件與格位、各片預期品級及人工標註的缺陷範圍。公司影像保留在現場；可以把匿名測例 ID 與統計提交至專案。

至少涵蓋正常品、尺寸 A、尺寸 B、尺寸 NG、暗缺陷、亮缺陷、淡色線、背景紋理、缺片、無法找物件、不同影像尺寸、不規則 ROI 邊界與多參數群組。每個重要異常均需對應良品反例。

## 3 功能驗收案例

全部初始狀態為待執行；發現與既有實作不同時，記錄實際結果，不直接改預期以配合錯誤。

| 案例 | 操作與條件 | 應確認的結果 |
|---|---|---|
| C01 | 缺少 device-settings.ini 開啟程式 | 預設精度 1、換算關、允許連線關、角色 Operator |
| C02 | 各群組設定套用後重開 | 僅對應欄位改變；其他已保存欄位保留 |
| C03 | 操作員／工程師／管理者／總監控切換 | 頁面範圍正確；重新啟動沿用角色 |
| C04 | 重複點同頁及功能區空白 | 不重建右側或重啟運算 |
| C05 | 100%／125%／150%／200% DPI 和縮小視窗 | 文字、框線、按鈕不遮擋，可到達全部設定 |
| C06 | 匯入 Recipe 但不套用 | 目前流程和作用中 Recipe 不變 |
| C07 | Recipe A→B→A，含相同內部 ID | 來源、菜單、MASK、結果不錯接 |
| C08 | 改工作參數、更新目前、另存新 Recipe | 目錄快照與作用中識別符合操作 |
| C09 | 新建參數 | 工作設定重設；全域精度、連線及名稱保留 |
| C10 | 多參數分組保存再載入 | 群組及所有子參數、來源關聯完整 |
| C11 | 找多片、改格位與旋轉分析 | 編號、矩陣與影像位置一致 |
| C12 | 同尺寸換圖及不同尺寸換圖 | ROI 保留／拒收與提示符合入口規則 |
| C13 | 建三個 ROI、改名、群組選三個 | 所有物件皆映射三框，ID 關聯不變 |
| C14 | 群組內 ROI 重疊 | 同條件重疊區不重複計算；顯示和運算一致 |
| C15 | 啟用條件無 ROI 組或刪除被引用 ROI | 回報缺少有效範圍，不默認全圖 |
| C16 | 點清單文字、勾選框和排序按鈕 | 只有勾選框改成員，套用後順序保留 |
| C17 | Single／Parallel，部分線未命中 MASK | 數值、0 樣本、最小最大顏色與統計一致 |
| C18 | X/Y 精度不同的水平／垂直／斜線 | mm 與方向公式一致，裁切顯示不改值 |
| C19 | MIN(1)、AVG(1)、MAX(1)、舊聚合式 | Parallel 統計與既有語法相容 |
| C20 | 錯誤式、除零、缺紀錄和不完整規格 | 回報待確認／錯誤，不偽判通過 |
| C21 | A 全通、A 失敗 B 通、A/B 失敗 | 每片分別 A、B、NG |
| C22 | A 未知、獨立 B、沒有任何條件 | 依規格書第 5 章逐項確認 |
| C23 | 保存平場後重啟、換同規格新圖 | 使用保存曲線與正確 MASK，不借舊結果 |
| C24 | 各一般核心單獨套用 | 只更新該核心；完整執行才更新需要的其他工作 |
| C25 | 暗／亮邊界值、E/D 和 X/Y 篩選 | 門檻含等號，形態後不越 ROI，候選尺寸正確 |
| C26 | 七個一般核心啟停、用途標籤 | 停用圖片頁隱藏；標籤不改固定頁名 |
| C27 | 頻域規則矩形尾端、窄區、孔洞、旋轉 | 格尺寸完整、不讀 ROI 外黑區，無格不作通過 |
| C28 | 頻域 0.25／0.5／0.75／1／2／3X | 計算高度有變化，原圖落點不漂移 |
| C29 | 頻域門檻 1 與 10、對比和前處理 | 門檻方向正確；原始能量及相對分數均可追查 |
| C30 | 鄰格參考不足與一般缺陷排除 | 不足時不假算；相依工作完成後才最終比較 |
| C31 | 暗亮合併、距離 0／非0、納入頻域兩組 | 逐片整合、來源與框位正確，單圖／綜合圖一致 |
| C32 | 結果確認換頁再回來、改參數再執行 | 前者保留結果視角，後者確實更新 |
| C33 | 總覽首次連相機，不先開全域相機頁 | 能初始化、Connect、Preview |
| C34 | Software Trigger 原點是／否 | 是才 Encoder Clear 並繼續，否不繼續 |
| C35 | 持續取像／檢測首次啟動、換頁、返回 | 相機與模式持續，直到使用者停止；重點 L01 |
| C36 | 比檢測快的新影格連續輸入 | 一張在途、忙碌略過、無待判堆積與長期 RAM 增長 |
| C37 | 相機 Y 高度不符與無 Recipe | 保留圖、灰色待確認、原因與歷史符合設計 |
| C38 | 手動記錄開／關、圖片保留開／關 | 判定明細、圖片及重跑可用性各自正確 |
| C39 | 跨午夜、不同日期及 Recipe 篩選 | DB 日期與紀錄時間正確，摘要／明細一致 |
| C40 | 同筆重複點、另筆切換、右鍵重跑 | 避免重複載入；精確使用歷史 ParameterId |
| C41 | 歷史缺圖、缺快照、多參數無 ID | 明確拒絕，不猜選或改用目前 Recipe |
| C42 | 歷史後修改設備精度再重跑 | 記錄現有差異，驗證 L03 修正後的可追溯性 |
| C43 | 127.0.0.1 不同 Port 與跨電腦 | 正確監聽、ID 比對、相機與 TCP 燈號 |
| C44 | 同 ID 快速重連與多站並行重連 | 舊清理不影響新連線，驗證 L02 |
| C45 | 總控啟停、相機離線、監控關閉 | 模式互斥、紅灰燈號、拒絕／接受狀態正確 |
| C46 | 斷線期間多筆結果，再恢復 | 區分最新狀態與逐筆遺失；不宣稱可靠重送 |
| C47 | 磁碟滿、不可寫、存圖失敗、結束程式 | 檢測與記錄可追查，未保存圖片不得標示可重跑 |
| C48 | 多小時連續大圖與多條件 | 記憶體、句柄、時間與保存待處理量無無界增長 |

## 4 效能驗收

先確認演算法結果，再測效能。採同一電腦、相機與 Release 程式，固定影像／Recipe／精度，分別測平行關與開。每組保留暖機數、樣本數及所有時間資料。

至少量測來源就緒至判定發布的牆鐘、尺寸／缺陷並行牆鐘、前段處理、讀圖、顯示、存圖完成、格數、峰值 RAM、CPU、GDI／HANDLE、略過影格數。報告中位數、P95、最大值，並列例外與取消。

CPU 累計變少不一定等於使用者等待變少；反之工作累計較長也可能是同時執行。明確記錄是否使用快取及是否包含首次建立平場／MASK。

## 5 驗收紀錄格式

每筆紀錄至少寫案例 ID、日期、程式 commit、Recipe hash、ParameterId、圖片 hash／尺寸、設備精度、電腦、步驟、預期、實際、品級／數值、耗時、記憶體、通過或失敗、證據路徑與執行者。

設備驗收目標如節拍、容許誤檢／漏檢、量測誤差、保留天數、停機恢復時間與可接受略過率，需由產品及現場訂定；本文件不代填未量測門檻。
