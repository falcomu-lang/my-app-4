## 如何判讀狀態

「已實作」表示目前原始碼中可以追到對應路徑。「待驗證」表示仍需實際影像、GUI、硬體或網路確認。「已知風險」表示靜態追讀發現具體問題，尚未藉由這次文件工作修正。「目標」表示後續建議。

本次工作重新核對主要流程、UI 文字、設定模型、通訊合約及儲存路徑，沿用既有全檔案結構盤點。沒有新增檢測演算法或改動設備控制程式。未進行相機、米輪及跨電腦通訊驗收；文件的版面檢查另有記錄。

## 維護方式

每次功能調整，先更新對應手冊章節與規格，再更新程式對照表及驗收案例。文件需記錄程式提交與核對日期。已知問題只有在完成修正並有驗證證據後才能標示結案。效能數字需附影像規格、參數、電腦及測量範圍。

docs/tools/build_documents.py 可從 Markdown 重新產出兩份 Word。PDF 應由同一份 Word 轉出並逐頁檢視；匯出與檢視方法見 [文件產出說明](tools/README.md)。
